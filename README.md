# Rule-Based Chatbot
This is a beginner Java chatbot project that gives simple replies based on user input using if-else conditions and loops.

## Features
- Responds to greetings
- Responds to help command
- Tells chatbot name
- Responds to weather and thanks
- Exits when user types bye

## Technologies Used
- Java
- VS Code

## How to Run
1. Compile the code:
   javac Chatbot.java

2. Run the program:
   java Chatbot
